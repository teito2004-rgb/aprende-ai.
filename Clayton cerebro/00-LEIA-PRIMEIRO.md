# Clayton cérebro — cópia no GitHub

Porta de entrada. Aqui fica reunido, num lugar só, o que estava espalhado pelas conversas e sessões: skills, agentes, comandos e prompts.

**Esta é uma cópia parcial e sem dados pessoais.** O repositório é público, então nomes de clientes viraram `[Cliente A]`…`[Cliente D]`, os caminhos do PC viraram `%USERPROFILE%\...` e o link do canal virou `[link do canal]`. A base completa continua no PC, em `Documents\Codex\Clayton cerebro`. Os originais completos das skills estão nas skills do Claude.ai.

## Regras de uso
- Regras fixas valem sempre: **nunca gastar créditos de IA sem autorização para aquela chamada** (veja `../CLAUDE.md` e `../diretor-producao-ia/ferramentas/politica-creditos.md`).
- Padrão de um cliente vale só para aquele cliente.
- Ao alterar uma skill, alterar também o original no Claude.ai (Configurações → Skills); esta pasta é cópia de referência, não é o que o Claude carrega.
