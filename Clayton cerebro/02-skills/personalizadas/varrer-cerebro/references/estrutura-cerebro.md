```
Clayton cerebro/
├── 00-LEIA-PRIMEIRO.md      porta de entrada e regras de uso
├── 01-CONTEXTO.md           quem é Clayton, clientes, projetos
├── 01-AGENTES.md            equipe de agentes e fluxo
├── 02-SKILLS.md             catálogo de skills
├── 02-skills/               cópias das skills (personalizadas, producao, compartilhadas)
├── 04-conversas/            CATALOGO.md + extratos parciais de chats
├── 05-materiais-dos-projetos/   Markdown dos projetos
├── 06-programas-e-scripts/  INDICE.md + cópias de referência
```

## Contexto fixo conhecido

- Clayton estrutura uma produtora/agência de conteúdo orgânico para Instagram Reels e YouTube Shorts: pesquisa, análise, roteiros originais e edição. Pesquisa com evidências verificáveis e sem promessa de viralização.
- Clientes citados nas referências: [Cliente A], [Cliente B], [Cliente C], [Cliente D]. Confirmar briefing antes de aplicar padrões.
- Fluxo de referência dos agentes: briefing → Nico e Mayara → análises necessárias → Chico → Pablo → revisão e aprovação → produção → resultados. Mobilizar só os agentes que o pedido exige e nunca fingir participação de quem não atuou.
- Avatar/clone visual de Clayton não é o mesmo que os perfis de agentes.

## Quando a base não foi enviada

Criar apenas o que o relatório precisa: `09-varreduras/` e, se o usuário pedir, os arquivos 00 a 02 com o que foi aprendido. Dizer claramente que é uma base nova e parcial, para não parecer a base completa.
